## 📊 Featured Project

### Telecom Customer Churn Analytics

An end-to-end data analytics and machine-learning project analyzing **7,043 telecom customers** to understand churn behavior and identify high-risk customer segments.

**What I worked on:**

* Cleaned and explored customer data using Python
* Used SQL to analyze churn across customer segments
* Identified key churn patterns based on contract, payment method, tenure, and services
* Built a class-balanced Logistic Regression model
* Achieved **0.841 ROC-AUC** and **78.3% recall**
* Prepared model outputs for Power BI-based visualization and business analysis
